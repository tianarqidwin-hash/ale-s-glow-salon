# Glow Salon — Skin Clinic Game

Game edukasi berbasis HTML, CSS, dan JavaScript.

## Menjalankan
1. Ekstrak folder proyek.
2. Buka folder di VS Code.
3. Jalankan `index.html` dengan ekstensi Live Server, atau gunakan server statis lain.

## Pembaruan versi ini
- Menggunakan gambar karakter pasien perempuan/laki-laki yang diberikan pengguna.
- Menggunakan ilustrasi dokter/terapis dari gambar referensi.
- Enam pelanggan dipertahankan.
- Bank soal 50 butir tetap dipertahankan; setiap shift mengambil 10–15 soal secara acak.
- Timer tantangan soal 60 detik per soal, dengan indikator visual dan alarm.
- Opsi jawaban dibuat konsisten secara visual (lebar penuh dan tinggi minimum seragam).
- Efek suara, musik latar opsional, dan suara teks tetap tersedia.

Catatan: game ini untuk edukasi, bukan alat diagnosis medis.
